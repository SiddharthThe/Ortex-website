04Capabilities

What it does.

  1. 01

    Cross-platform context

    One context model shared across ChatGPT, Claude and Gemini.

  2. 02

    Incremental conversation capture

    Only new messages are processed as the conversation grows.

  3. 03

    Local context processing

    Estimation and reduction run client-side.

  4. 04

    Platform adapters

    Isolated parsers per interface, so a UI change stays contained.

  5. 05

    Cross-tab orchestration

    The service worker routes context between open tabs.

  6. 06

    Token-aware transfer

    See approximate size before sending, trim when it's too large.
